# data4000-python-exercises
DATA 4000 Python Exercises

This repository contains my Python exercises for DATA 4000: Python with AI.

Exercises
Exercise 1: Profit Margin Calculator

Calculates profit and profit margin using revenue and cost.

Exercise 2: Credit Score Evaluator

Uses conditional statements to evaluate a customer's credit score.

Exercise 3: Customer Greeting Formatter

Uses functions and string methods to create a personalized customer greeting.

Exercise 4: Tax Bracket Determiner

Determines an income tax bracket and calculates the estimated tax.

Exercise 5: Product Category Matcher

Uses match-case statements to categorize products based on the product name.

Tools Used
Python 3.x
Visual Studio Code
GitHub
Assumptions

The exercises use the information entered by the user and follow the requirements provided in the DATA 4000 assignment.
